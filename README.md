# 公众号改写排版台

一个本地优先的 Chrome Manifest V3 插件，用来把任意网页内容整理成公众号可发布的稿件，并支持多图文草稿、发布状态轮询以及网页编辑器辅助同步。

## 当前能力

1. 抓取最近浏览网页的正文和配图
2. 调用 OpenAI 兼容接口改写成公众号文章结构
3. 在扩展内完成标题、摘要、导语、封面和正文排版
4. 支持 1 篇主篇 + 最多 7 篇副篇的多图文草稿包
5. 自动把正文图片上传到公众号图文图片接口
6. 自动把封面上传到公众号素材接口
7. 一键推送到草稿箱，或直接提交发布
8. 自动按 `publish_id` 轮询发布状态
9. 刷新工作台后，如果发布还没结束，会自动恢复轮询
10. 支持当前篇前移/后移，调整多图文顺序
11. 支持把整组草稿导出成 JSON，再导回继续编辑
12. 支持把当前篇辅助同步到 `mp.weixin.qq.com/cgi-bin/appmsg`
13. 继续支持复制正文 HTML、复制 Markdown、导出预览 HTML
14. 内置欢迎页、帮助中心、权限说明、隐私政策和服务条款页面

## 工作流

1. 打开 Chrome 的 `chrome://extensions/`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前目录 `/Users/junshengma/Desktop/gzh`
5. 进入插件“配置 API”页面
6. 填写 AI 改写接口：`API Base URL`、`API Key`、`Model`
7. 填写公众号直连配置：`AppID`、`AppSecret`、默认作者、默认发布模式
8. 打开任意文章页，点击插件图标，选择“抓取当前页并打开编辑台”
9. 在编辑台里点“AI 改写”
10. 如需多图文，在“草稿包管理”里新增或复制副篇
11. 如需调整顺序，可直接前移/后移当前篇
12. 如需跨设备继续编辑，可先导出草稿包 JSON
13. 调整标题、摘要、导语、封面、正文和排版主题
14. 点“按当前模式执行”或“强制直接发布”
15. 如需辅助落到公众号网页后台，可点“同步到网页编辑器”

## 重要说明

- 当前直连发布使用的是公众号官方接口，需要你自己的 `AppID` 和 `AppSecret`
- 如果公众号接口开启了 IP 白名单，请把当前出口 IP 加入公众号后台开发配置，否则获取 `access_token` 会失败
- 正文里的外部图片会在发布前重新上传到公众号图文图片接口；封面图会单独走永久素材接口
- 发布状态轮询接口按 `publish_id` 查询；当前实现会自动轮询，也支持手动再查一次
- 如果你中途关闭工作台，只要本地还保留最近一次 `publish_id`，重新打开后会继续轮询
- 网页编辑器辅助模式同步的是“当前选中的这一篇”，不是整组多图文
- 这个版本把 `AppSecret` 存在扩展本地存储里，只适合个人或小团队本地使用，不适合直接商用
- `host_permissions` 现在是 `http/https` 全开，方便抓取图片和调用不同接口；如果准备上架商店，应该缩减到你实际需要的域名
- Chrome Web Store 真正上架前，最好把内置的隐私政策/条款/帮助页面再部署到公开域名，作为商店外链

## 目录结构

```text
manifest.json
src/
  background/
  options/
  popup/
  shared/
  workspace/
```

## 主要模块

- `src/workspace/`：公众号风格工作台，负责多图文草稿包、标题摘要封面、正文编辑、预览和发布
- `src/shared/wechat.js`：公众号直连发布链路，负责 token、图片上传、草稿创建、提交发布和状态查询
- `src/content-scripts/wechat-editor-helper.js`：网页编辑器辅助同步脚本
- `src/shared/ai.js`：网页内容改写提示词和 OpenAI 兼容请求
- `src/background/service-worker.js`：扩展消息总线与后台调度
- `src/pages/`：欢迎页、帮助中心、权限说明、隐私政策和服务条款

## 当前限制

- 公众号接口对正文 HTML 长度有限制，超长文章可能需要精简
- 某些站点的图片如果带强防盗链，扩展下载图片时可能失败
- 网页编辑器辅助同步依赖微信后台页面结构，自动写入失败时会退回到“复制 HTML + 手动粘贴”
- 仍然没有后端鉴权、账号体系、配额与团队协作
