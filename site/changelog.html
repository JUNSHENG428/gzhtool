helper-v0.2.0 2026 年 5 月

桌面助手 v0.2.0 · 安全加固（强烈建议升级）

新增

  • 默认开启访问令牌鉴权：抓取接口必须携带本机生成的随机令牌才能调用，防止电脑上其它程序偷偷使用助手；窗口里点「复制 helper 地址」即可拿到带令牌的完整地址。
  • 默认拒绝抓取本机 / 内网地址：只允许公网 http / https 页面，避免助手被误用为内网探测跳板；高级用户可显式开启放行。
  • 跨源来源白名单收窄：只接受浏览器扩展与本机调试地址的请求。

改进

  • 窗口新增「安全凭据」卡片：脱敏显示当前令牌，一键重置。
  • 抓取失败返回稳定错误码，扩展端能给出更准确的差异化提示。

下载：GitHub Release · 升级方法：关掉旧版 → 下载新版 zip → 替换 → 启动

PLATFORM AI 2026 年 5 月 3 日

平台 AI 服务上线 · 月度 token 配额 + 年费独享自定义 Key

新增

  • 平台 AI 模式（默认推荐）：由润笔托管 LLM 调用，不再需要用户自己注册任何服务商账号。Free 30 次 / 月（DeepSeek V4 Flash 经济档），月费 5M token / 月（增加 DeepSeek V4 Pro 标准档），年费 20M token / 月（再增加 GPT-4o 旗舰档）。
  • 反向 gating · 自定义 API Key 仅年费可用：年费会员可在扩展端切到「使用我自己的 API Key」模式，正文直发服务商不经过润笔服务器，不计平台额度——给重度用户最大灵活度。
  • 三处用量进度条：dashboard 控制台首页、扩展 options 设置页、popup「我的」tab 都能看实时月度用量（token 数 / 调用次数 / 剩余 / 重置倒计时），数据来自同一个 worker 端点 /api/llm/usage。
  • worker 上游 fallback 链：DeepSeek 5xx 自动降级到 OpenAI 反之亦然；4xx 不降级避免无限循环；响应头 X-Platform-Tier-Downgraded / X-Platform-Fallback-From 让前端能感知。
  • Cloudflare KV 限流：每分钟 RPM 上限按 plan 分（Free 5 / 月费 30 / 年费 100），防恶意刷 + 防 cost 暴涨。

改进

  • 月度配额按 UTC 自然月每月 1 日重置（与虎皮椒订阅周期对齐），不引入"滚动 30 天"复杂度。
  • worker 端 token 计量走 D1 ON CONFLICT 原子 upsert，不存 prompt / completion 文本（仅 token 数 + metadata），llm_audit_log 表保留 90 天后定时清理。
  • 隐私政策同步更新：明确披露平台 AI 模式的数据流、与上游 LLM 服务商的零训练合约、BYOK 模式的彻底退出路径。详见隐私政策 §2.2 / §3 / §4。

兼容性

  • 老 Pro 用户自动映射到「年费」档位，享 20M token / 月配额；现有自定义 API Key 配置完整保留，不影响升级路径。
  • 扩展端默认仍为 BYOK 模式（保护已配好 apiKey 的老用户），新装用户登录后自然走平台 AI。
