FAQ

常见问题

开通后多久能用？

支付成功后我们的服务器会在 30 秒内自动给你购买使用的账号开通 Pro 权益。打开扩展，用购买时的邮箱登录即可看到 Pro 已激活，无需手动输入任何编码。

支持几台设备？

Pro 会员账号最多可同时在 3 台设备上激活。换电脑时打开旧设备 → 解绑本机 → 在新设备登录账号即可继续使用。

退款政策？

7 天内无理由退款，回邮件即可，无需理由。

数据会上传给你们吗？

分两种 AI 模式说：
平台 AI 模式（免费 / 月费默认）：你点 AI 改写时文章正文会经过我们的 Cloudflare 服务器临时转发到上游 LLM（DeepSeek / OpenAI），但我们不存储正文——只记录 token 用量、模型名、错误码。详见隐私政策。
自定义 API Key 模式（年费独享）：你的文章正文直接从扩展端发到你绑定的 API Key 服务商，不经过我们。我们对内容零接触。
所有素材、草稿、改写结果都仅存在你浏览器本地。我们的服务器另外还用来：账号登录、会员校验、订阅支付回调。

平台 AI 用完了怎么办？

免费版 30 次 / 月费 5M token / 年费 20M token，按 UTC 自然月每月 1 日重置。撞顶后可以：1）等下月重置；2）升级到更高档套餐；3）（年费）切到「使用我自己的 API Key」模式，用自己的 OpenAI / DeepSeek 账号继续跑，不计平台额度。

为什么年费才解锁「自定义 API Key」？

月费档由平台托管 LLM 调用、按 token 配额计费——这是平台主营收入。年费用户多半已有自配 LLM 资源（公司 OpenAI 账号 / 自部署模型 / 偏好特定服务商），平台不再插中间赚 token 差价，让出最大灵活度。等于「年费 = 平台 AI 大额度 + 自由切换 BYOK」。
