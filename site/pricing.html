FAQ

常见问题

购买后多久能用？

支付成功后我们的服务器会在 30 秒内通过 Webhook 收到回调，并把 License Key 发到你的邮箱。打开扩展设置页的「会员激活」Tab，登录账号或粘贴 Key 即可解锁。

支持几台设备？

同一个 License Key 可同时绑 3 台设备。换电脑时打开旧设备 → 解绑本机 → 在新设备上重新激活即可。

退款政策？

7 天内无理由退款，回邮件即可，无需理由。

数据会上传给你们吗？

不会。所有素材、草稿、改写结果都存在你浏览器本地。我们的服务器只用来：1）登录与会员校验；2）支付回调。AI 调用走的是你自己填的 API Key，不经过我们。
