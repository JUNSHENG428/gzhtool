隐私政策

最近更新：2026 年 4 月 22 日 · 适用于 润笔 Chrome 扩展及 docuearn.com 网站

English Summary for Reviewers: DocuEarn is a Chrome extension and web dashboard for Chinese-language writers publishing to WeChat Official Accounts. We collect only the minimum data needed to operate the service (account email, license status, anonymous usage counters). We do not sell user data, do not store the content of articles users write, and AI processing is done by the user's own OpenAI/Anthropic API key — we are not in the request path.

1. 我们是谁

DocuEarn（中文名"润笔"）是一款帮助中文创作者起草、改写并发布到微信公众号的 Chrome 扩展，配套有 docuearn.com 网站做账号管理与付费。 本政策说明我们收集了哪些数据、为什么收集、如何使用，以及你能如何控制。

2. 我们收集的数据

2.1 账号数据（仅在你注册时）

  • 邮箱地址（用于登录、密码重置、订阅开通通知）
  • 密码哈希（PBKDF2-SHA256，从不存储明文）
  • 设备指纹（用于多设备并发限制，由 user-agent + 时区等公开信息哈希得出）

2.2 使用数据（聚合 + 匿名）

  • 调用次数计数（如 "今日 AI 改写 3 次"），用于配额管理
  • 错误日志（仅记录错误码与堆栈，不含用户输入文本）

2.3 我们 不 收集的数据

  • 你写的文章正文 / 草稿 / 改写结果 —— 全部保存在你本机浏览器的 IndexedDB / localStorage
  • 你的 OpenAI / Anthropic / 其他 AI 服务的 API key —— 只保存在本机扩展存储，从不上传
  • 你抓取的素材原文 —— 全部本机处理
  • 你的微信公众号账号密码 / cookies —— 复用浏览器原生登录态，从不读取或上传

3. 数据如何处理

  • AI 调用：由扩展直接连到你配置的 AI 服务商（OpenAI / Anthropic / 兼容 API），我们的服务器 不 在请求链路上，看不到 prompt 内容。
  • 素材抓取：由扩展在你浏览器里执行，请求来自你自己的 IP，使用你已有的登录态，我们的服务器只下发"该抓什么"的指令模板。
  • 账号 / 付费数据：存储在 Cloudflare D1（部署在新加坡边缘节点），仅用于身份验证与配额管理。
  • 支付数据：由第三方支付平台处理，我们仅接收支付平台的回调通知（支付状态、订单号、客户邮箱），不存储任何银行卡信息。

4. 数据共享

我们 不会 出售、出租、或与第三方共享你的个人数据。例外：

  • 第三方支付平台 —— 仅在你开通 Pro 会员订阅时
  • 邮件服务（Resend）—— 仅在发送密码重置 / license 邮件时
  • 法律强制要求（如法院传票），我们会在合规前提下尽量通知你

5. 你的权利

  • 查看：登录 控制台 即可查看账号与设备列表
  • 导出：所有正文 / 模板都在你本机存储中，可在扩展设置 → 数据 中导出
  • 删除：邮件 support@docuearn.com，我们会在 7 个工作日内删除你的账号与所有服务端数据
  • 解绑设备：在控制台 → 我的设备 中可即时解绑

6. Cookies / 本地存储

docuearn.com 网站：仅使用一个 session cookie 维持登录态，不使用任何第三方追踪 / 广告 cookie。

扩展本地存储：使用浏览器的 chrome.storage.local 存放配置，不会跨站点共享，卸载即清除。

关于 cookies 权限：扩展声明了 cookies 权限，仅用于「AI 选题代笔」功能： 通过 chrome.cookies.getAll() 检测你是否已在小红书 / X / Reddit / 知乎登录 （即「关键 cookie name 是否存在」）。我们 只读取 cookie 的名字 （如 web_session、auth_token），不读取 value， 判断结果只在本地内存使用，不写入存储、不发送到任何服务器。缺登录时只会引导你开新 tab 自己登录， 不会模拟登录、不会代你提交账号密码。

7. 儿童

本服务面向 18 岁及以上的内容创作者，我们不刻意收集任何 13 岁以下用户的数据。

8. 政策变更

如有重大变更（如新增数据收集），我们会通过登录注册时填写的邮箱通知你；非重大变更只更新本页面上方的"最近更新"日期。

9. 联系

有任何隐私 / 数据相关问题，请邮件至 support@docuearn.com。我们承诺 3 个工作日内回复。
