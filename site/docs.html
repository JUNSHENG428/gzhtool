使用文档

最近更新：2026 年 5 月 3 日 · 从安装到发布全流程，约 5 分钟可上手

5 分钟快速开始

第一次使用，按这个顺序走一遍即可发出第一篇文章：

  1. 安装扩展：到 Chrome 网上应用店搜「润笔 DocuEarn」一键安装
  2. 注册账号：到 login 用邮箱或 Google 一键登录注册（免费版自带 30 次 / 月平台 AI）
  3. 选 AI 来源：扩展 → 设置 → AI 改写接口 → 顶部「AI 服务来源」二选一：◉ 使用润笔平台 AI（推荐 · 即开即用）/ ○ 使用我自己的 API Key（年费独享 · 用自己的 OpenAI/DeepSeek 账号）
  4. 配置公众号：扩展 → 设置 → 公众号，填 AppID + AppSecret（从公众号后台 → 开发 → 基本配置 拿）
  5. 开始创作：从热榜挑选题 → AI 改写 → 排版 → 一键发草稿到公众号后台

该选平台 AI 还是自定义 API Key？

润笔的 AI 改写支持两条路径，按你的情况二选一：

维度 平台 AI 模式（默认推荐） 自定义 API Key 模式（年费独享）
谁能用所有用户（Free / 月费 / 年费）仅年费会员
需要自己注册服务商账号？不需要需要（OpenAI / DeepSeek / Kimi 等）
计费方式按月度 token 配额（包含在套餐里）按服务商实际 API 费用（一篇约 ¥0.05-0.3）
正文路径扩展 → 润笔 Worker → 上游 LLM（不持久化）扩展 → 你绑定的服务商（不经过润笔）
可调模型economy / standard / flagship 三档（按套餐解锁）服务商提供的所有模型
额度撞顶处理等下月重置 / 升级套餐服务商账户充值即可

普通用户：留默认平台 AI 即可，登录账号就能用，撞顶前不用关心任何服务商配置。

有自配 LLM 资源的用户（公司 OpenAI 账号 / 自部署模型 / 偏好特定服务商）：升级年费会员后切到自定义 API Key 模式，用自己的资源，零中间成本，正文不经过润笔服务器（合规优势）。

详细流程 · 发出你的第一篇文章

预计耗时 8-15 分钟（其中 AI 改写约 30 秒）

Step 1 · 配置 AI Key
打开扩展 → 顶部「设置」按钮 → 「AI 模型」标签页。
以 OpenAI 为例：粘贴 sk-... 到「API Key」框 → 「base URL」保持默认 → 「测试连接」按钮 → 看到绿色 ✓ 即可保存。
国产大模型（DeepSeek / 智谱）需要把 base URL 改成各自的 endpoint，详见各服务商官方文档。
Step 2 · 配置公众号
扩展设置 → 「公众号」标签页：
  • AppID / AppSecret：登录 公众号后台 → 开发 → 基本配置 → 复制粘贴
  • API 代理 URL（可选）：如果你部署了阿里云 FC 代理，填这里就走代理
  • 保存后点「测试连通性」按钮，看到绿色 ✓ 即配置成功
Step 3 · 抓选题
扩展 workspace → 顶部 tab 「热点」→ 选热榜源（今日头条/知乎热榜/微博热搜/...）→ 看到感兴趣的话题点「抓正文」。
单篇正文抓不到时（多见于反爬严的网站），换「DrissionPage 增强抓取」（需 Pro + 桌面助手）。
Step 4 · AI 改写
抓到的正文进入「改写」面板 → 选写作风格模板 → 按「开始改写」按钮 → 30 秒内出结果。
觉得不够好？右上角「润色 / 扩写 / 缩写」按钮可以多轮迭代。
Step 5 · 排版
改写完跳到「排版」面板 → 顶部样式选择器选一款（推荐先试 The New Yorker 或 Kinfolk）→ 实时预览效果 → 不满意可换其他样式。
排版完点「导出 HTML」可直接复制粘贴到公众号后台 HTML 源码模式。
Step 6 · 一键发草稿
排版面板右上角「发到公众号草稿」按钮 → 自动调微信 API 上传图片 + 创建草稿 → 看到「✓ 已推草稿」即成功。
打开公众号后台 → 草稿箱 → 找到刚才的草稿 → 检查 → 群发 / 定时发布。

进阶用法

多公众号矩阵管理（Pro）
在「设置 → 公众号」可同时绑定多个 AppID。workspace 顶部下拉框切换当前操作的公众号，发布时自动用对应账号。
Agent 跑批选题
workspace → 「Agent」面板 → 配置选题主题 / 风格偏好 → AI 自动从多个热榜源筛选 + 评分（热度 / 相关性 / 时效）+ 给出 brief。适合每天定时跑一次拿 5-10 个候选选题。
群发策略（仅认证服务号）
扩展 → 设置 → 公众号 → 群发策略：
  • 全员群发：每月 4 次硬上限，自动统计已用次数
  • 按标签群发：先「拉取本号所有标签」→ 选 tag → 不消耗月配额
本地数据导出 / 导入
扩展 → 设置 → 数据 → 导出 JSON 备份。所有改写结果 / 模板 / 配置都在你本机存储中，卸载扩展前记得先备份。
