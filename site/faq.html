安装与登录

为什么我用 Google 登录了官网，扩展里却登不上？

因为 Chrome 扩展运行在 chrome-extension:// 域下，Google 登录无法在扩展环境中直接运行。你需要先在网页控制台为插件单独设置一个登录密码：

  1. 登录 docuearn.com 控制台
  2. 右侧账号卡上方会出现淡黄色提示 「为插件设置登录密码」
  3. 点开按钮，输入你想要的密码（不需要旧密码）
  4. 回到扩展，用同样的邮箱 + 这个新密码即可登录

这个密码只用于扩展登录，不影响你后续继续用 Google 一键登录网站。

忘记密码了怎么办？
  1. 打开 忘记密码页 输入注册邮箱
  2. 30 秒内会收到一封 「润笔 · 重置你的密码」 邮件，主题带 [润笔] 前缀
  3. 点邮件里的链接 → 设置新密码 → 用新密码登录

收不到邮件？ 先去垃圾邮件文件夹找一下（QQ / 163 邮箱很容易拦截海外发件人）。如果 5 分钟内仍没收到，邮件 support@docuearn.com 让我们手动重置。

提示「设备数量已达上限」是什么意思？

免费用户最多绑定 1 台设备，Pro 用户最多 3 台。设备数是按浏览器指纹（user-agent + 屏幕分辨率 + 时区等）计算的，同一台电脑换浏览器或重装系统会算成新设备。

解绑老设备：登录 控制台 → 「我的设备」→ 点旁边的「解绑」按钮 → 即时生效。

付费与会员

付完款之后多久能用上 Pro 功能？

支付成功后通常 10 秒内会自动激活：

  • 网页控制台的会员状态会立刻变成 Pro
  • 扩展端的状态需要打开 workspace 页面或者按一下「刷新会员状态」按钮，会在几秒内同步

如果支付完 1 分钟仍未激活，请提供 支付订单号 + 注册邮箱 邮件 support@docuearn.com，会有人工核对。

付款方式有哪些？

所有支付都是一次性买断 1 个月或 1 年，不会自动续费，到期前我们会在控制台和插件里提醒你手动续费。

会员快到期了，会通知我吗？

会的。到期前 7 天内，下面 4 个地方会同时显示提醒：

  • 插件 workspace 顶部 pill：PRO · N天后到期（琥珀色）
  • 插件会员 hero 卡：「Pro 还剩 N 天到期」+ 主按钮变「立即续费 Pro」
  • 网页控制台顶部琥珀横幅 + 「立即续费」按钮
  • 定价页 Pro 用户的按钮自动从「已开通」切换为「立即续费」

这段时间 Pro 功能完全不会中断，到期当天才会真正降级到 Free。

Free 版和 Pro 版的区别？

三档对比（按 AI 调用配额排序）：

额度按 UTC 自然月每月 1 日重置。详细对比见 定价页。

AI 改写

AI 改写要不要单独充值？

看你用哪种模式：

  • 平台 AI 模式（Free / 月费默认 / 年费可选）：润笔自家托管，**包含在套餐价格里**——Free 30 次 / 月、月费 5M token / 月、年费 20M token / 月，不需要额外注册任何服务商账号，安装扩展登录账号即可用。撞顶后等下月重置或升级套餐即可。
  • 自定义 API Key 模式（年费独享）：用你自己注册的 OpenAI / DeepSeek / Kimi / 通义千问 / 智谱 等服务商账号，调用费用从你自己的 API 账户扣，不计入平台额度。常见模型一篇文章改写约 ¥0.05-0.3 元。我们对正文零接触。

新装用户默认走平台 AI 模式（开箱即用），扩展端「设置 → AI 改写接口」可切到自定义 Key 模式。

怎么切换平台 AI 和自定义 API Key？

扩展「设置 → AI 改写接口」顶部有个二选一 radio：

  • ◉ 使用润笔平台 AI（推荐 · JWT 鉴权 · 月度托管）
  • ○ 使用我自己的 API Key（年费独享 · 不计平台额度）

切到平台模式后，下方会出现「模型档位」下拉（economy / standard / flagship）+ 当月用量进度条；切到 BYOK 模式则显示原有的 8 家服务商预设 + apiBaseUrl + apiKey + model 配置。月费 / 免费用户切到 BYOK 模式时调用会被拦下提示升级年费。

平台 AI 用完了怎么办？

选项三选一：

  1. 等下月重置：UTC 自然月每月 1 日 00:00:00 自动 reset，dashboard 控制台与扩展 popup「我的」tab 都能看到 N 天后重置的倒计时。
  2. 升级套餐：Free → 月付（30 次 → 5M token，扩 ~166x）；月付 → 年付（5M → 20M，扩 4x 且解锁 GPT-4o + 自定义 Key 逃生口）。
  3. 切到自定义 API Key 模式（仅年费）：用自己的 OpenAI / DeepSeek 账号跑，不计平台额度。
AI 改写时报错「API key 无效」怎么办？

这是自定义 API Key 模式专属错误（平台模式不会出）。按这个顺序排查：

  1. API key 是不是复制时多了空格或换行？重新复制粘贴一次。
  2. API key 对应的账户余额是不是 ≤ 0？登录服务商后台确认。
  3. 「base URL」是不是和 key 来源对应？OpenAI 是 https://api.openai.com/v1/chat/completions，国产大模型各有自己的 endpoint。
  4. 有没有配置 IP 白名单？OpenAI 在中国大陆 IP 直连会失败，需要走代理。
  5. 实在搞不定？切回「使用润笔平台 AI」模式即可绕过——平台 AI 走我们托管的服务商账号，无需任何 API Key 配置。

仍未解决可邮件 support@docuearn.com，附上：使用的服务商 + base URL（不要发 API key 本身）+ 报错截图。

改写出来的内容太「AI 味」怎么办？

试试这几招：

  • 切换写作模板（10+ 种风格内置：深度行业观察 / 轻短嘴炮 / 亲历叙事 / 辟谣帖 …）
  • 在「自定义 prompt」里加示例文章片段，让 AI 模仿你的语气
  • 把模型换成 Claude 系列（claude-3.5-sonnet 自然度普遍优于 GPT）
  • 改写完后用「润色」按钮再过一遍，调低 temperature

微信公众号发布

提示「48001 api unauthorized」是什么？

这是微信官方从 2025 年 7 月开始执行的新规：未认证的订阅号无权调用 add_draft 接口。三种解决方法：

  1. 认证服务号（推荐）：每年 ¥300 微信认证费，认证后所有 API 全部解锁
  2. 使用「复制 HTML 到剪贴板」：在弹出的 modal 里点这个按钮，然后到 公众号后台 → 新建图文 → 右上角「</>」HTML 源码 → 粘贴。文字 + 排版完整保留，只是图片要手动重传一次
  3. 认证个人订阅号：2024 年起也开放了个人订阅号认证（年费同样 ¥300），适合个人创作者

详细背景见 WECHAT_LIMITATIONS.md。

提示「IP 不在白名单」怎么办？

微信公众号 API 默认只允许在公众号后台「设置 → 安全中心 → IP 白名单」里登记过的 IP 调用。两种解决方法：

  1. 把你家网关 IP 加到白名单（最简单，但你换 WiFi / 手机热点都得重加，运营商分配的动态 IP 会过几天就变）
  2. 部署阿里云函数计算（FC）代理（推荐）：用一个固定出口 IP 作为中转，扩展所有请求走代理出去。我们提供了开箱即用的代码：aliyun-fc/wechat-api-proxy/，按 README 部署后填到「扩展设置 → 高级 → 微信 API 代理」即可。月成本几乎为 0（FC 月免费额度内）
发出去的文章在暗色模式下看不清？

这是微信暗色模式只反转「没指定 color」元素的特性。我们已经在 v0.1 之后给所有段落 / 标题 / 列表加了显式 fallback 颜色（#2d3036 / #1f2228），新发的文章在暗色模式下完全可读。

如果你的文章是 v0.1 之前发布的，需要重新走一遍「排版 → 重新发布草稿」流程；或者直接到公众号后台手动改文字颜色。

怎么群发到所有粉丝？

需要 认证的服务号，订阅号无群发权限。在「扩展设置 → 公众号 → 群发策略」里选：

  • 全员群发：每月 4 次硬上限（微信平台限制，我们会自动统计已用次数）
  • 按标签群发：先调用「拉取本号所有标签」按钮，选一个 tag 就只发给该标签下的粉丝，不消耗月配额

桌面助手（DrissionPage 抓取）

什么时候需要装桌面助手？

只有 Pro 用户使用「DrissionPage 增强抓取」时才需要。普通抓取（基础 fetch + Cheerio）不需要。

触发场景：抓取微博 / 小红书 / 知乎等有强反爬、需要真实浏览器渲染才能拿到内容的网站。

mac 双击打开提示「无法验证开发者」怎么办？

因为我们暂时还没有买 Apple 开发者证书。第一次打开必须右键：

  1. 在 Finder 里右键 Runbi Helper.app → 打开
  2. 系统弹「无法验证开发者」→ 点 打开 / 仍要打开
  3. 之后双击就能直接开了

详细安装步骤见 USER_DOWNLOAD_HELPER.md。

Windows 提示「Windows 已保护你的电脑」怎么办？
  1. SmartScreen 弹窗里点 「更多信息」
  2. 下面会出现 「仍要运行」 按钮，点它
  3. 之后双击就能直接开了

可以。购买后 7 天内，且累计使用次数 ≤ 30 次的，无理由全额退款。

申请方式：邮件 support@docuearn.com，提供：

  • 购买时使用的邮箱

超过 7 天能退吗？
