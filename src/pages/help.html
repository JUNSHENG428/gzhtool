使用中遇到问题？这里有答案。

这里汇总了最常见的使用问题、推荐的使用步骤，以及出错时的排查思路。如果仍然没有解决你的疑问，可以通过页面底部的客服邮箱联系我们。

常见问题

最常见的 4 个问题

  • 为什么抓不到正文或图片？有些网页的正文是滚动后才加载的，图片也可能设置了防盗链。请先在原网页确认内容已经完整显示，再点一次抓取。
  • AI 改写总是失败怎么办？请在设置页确认接口地址、密钥和模型名填写正确，并确保所选模型支持较长的文章内容。
  • 推送到公众号失败怎么办？请确认公众号的 AppID 和 AppSecret 填写正确，并在公众号后台把你当前的 IP 加入白名单。
  • 在公众号编辑器里没自动填入内容？微信后台偶尔会调整页面结构。此时可以点助手面板上的「复制 HTML」，再到公众号编辑器里手动粘贴。

使用步骤

建议这样开始

  1. 1 第一次使用，先到设置页填好 AI 接口、公众号绑定信息、客服邮箱和官网信息。
  2. 2 打开任意一篇想转发的网页，点「抓取当前页并打开编辑台」先跑通一篇，再尝试多图文。
  3. 3 正式发布前，建议先推一次「草稿箱」在公众号后台预览，没问题再选择「直接发布」。

排查思路

按出错环节逐步排查

抓取网页
请确认当前页是普通的公开网页，内容已经完全加载，并且不需要登录即可查看。部分网站会有反爬限制，可能无法抓取。对应错误码：SCRAPE_NO_CONTENT
网络超时
请检查本地网络是否正常，或目标服务（AI 接口 / 公众号接口）是否可用。稍后重试通常可以解决。对应错误码：NETWORK_TIMEOUT
AI 认证失败
密钥无效或已过期，请到设置页重新填写 API Key。对应错误码：API_AUTH_FAILED
AI 请求频率受限
请求过于频繁或账户额度不足。请稍等片刻后点击「重试」，或升级 API 套餐。对应错误码：API_RATE_LIMITED
AI 接口异常
接口地址或模型名称不正确，或 AI 服务暂时不可用（5xx）。请在设置页确认接口地址是完整的 chat completions 地址，并检查模型名拼写。对应错误码：API_BAD_RESPONSE
公众号 IP 白名单
公众号后台开启了 IP 白名单限制。请登录公众号后台，依次进入「开发 → 基本配置 → IP 白名单」，将当前出口 IP 添加进去，然后重新推送。对应错误码：WECHAT_IP_NOT_WHITELISTED
公众号凭证无效
AppID 或 AppSecret 填错，请在设置页核实后重新保存。对应错误码：WECHAT_INVALID_SECRET
图片下载失败
原站可能设置了防盗链或图片链接已失效。可以尝试手动保存图片后，直接插入到编辑器中，或更换防盗链的图床链接。对应错误码：IMAGE_DOWNLOAD_FAILED
图片上传失败
图片格式不符合公众号要求（支持 JPG / PNG / GIF / BMP），或文件超过大小限制。请先压缩图片后再重试。对应错误码：IMAGE_UPLOAD_FAILED
素材太大
图片或封面素材超过公众号接口大小上限（通常为 10 MB）。请压缩图片后重试。对应错误码：WECHAT_MEDIA_TOO_LARGE
等待发布
点击发布后，页面会自动查询发布状态。即使中途关掉页面，下次打开时也会继续查询，请耐心等待。
