          这个账号没有 API 发布权限

          公众号后台返回了 48001 / 53400，意思是：当前账号没有「调用 draft/add 或 mass/sendall」的接口权限。

          常见原因：

          • 个人主体公众号 / 未认证企业号：本身就没有这些接口。
          • 2025-07 起：未认证账号被微信进一步收紧权限。
          • 订阅号：原本就没有 mass/sendall，也无法 API 发草稿。

          兜底姿势：点下面的「复制 HTML」按钮，把已经排好版的 HTML 复制到剪贴板，然后到公众号后台「素材管理 → 新建图文」点正文区右上角「<> HTML 源码」粘贴即可。

          推荐：浏览器登录模式（最快上手）

          • 不需要申请 AppID / AppSecret，也不用配 IP 白名单

          已有 AppID + AppSecret 的认证服务号也可以用「API 模式」，支持自动保存草稿和群发。
