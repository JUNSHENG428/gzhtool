第 1 步AI 改写接口

支持任何兼容 OpenAI 格式的接口，例如 OpenAI、OpenRouter、Azure、DeepSeek、月之暗面，或你已有的代理地址。

第一次配置？点这里看图文教程
  1. 去 OpenAI 或 OpenRouter 申请一个 API Key（OpenRouter 支持国内信用卡和 Apple Pay）。
  2. 把 Key 粘贴到下方「API Key」框；不要把 Key 直接发给别人。
  3. 「接口地址」用对应平台的 chat completions 地址；OpenAI 官方就是默认值。
  4. 「模型名称」填该平台支持的型号，常用便宜的：gpt-4.1-mini、gpt-4o-mini、deepseek-chat、openai/gpt-4o-mini（OpenRouter）。
  5. 填完点「测试连接」，看到「✅ 连接成功」就说明可用。

品牌与联系方式进阶

这些信息会自动显示在欢迎页、帮助中心和政策页面上，方便用户在需要时联系到你。

默认改写偏好可选

这些偏好会在每次打开编辑台时自动填入，你仍然可以在编辑时临时调整。留空也能用，AI 会按内置默认风格写。

第 2 步公众号直连发布可选

填好后可一键把改写好的文章推到公众号草稿箱或直接发布。如果只用 AI 改写、不直推到公众号，这一节可以跳过。

不知道 AppID/AppSecret 在哪？点这里看获取步骤
  1. 登录 微信公众平台（订阅号 / 服务号 / 个人订阅号都行）。
  2. 左侧菜单 → 设置与开发 → 开发接口管理（旧版叫「基本配置」）。
  3. 页面里能看到 开发者 ID（AppID） 和 开发者密码（AppSecret）。AppSecret 第一次生成后会隐藏，记得本地存好。
  4. 同一页找到「IP 白名单」，把你当前电脑的出口 IP 加进去（百度搜「我的 IP」可看到当前 IP），否则会提示 40164。
  5. 个人订阅号没有「群发图文」权限，但可以推到「草稿箱」，之后在手机微信里手动发布。

注意：测试只能验证 AppID/AppSecret 能换到 token，不代表你账号有「群发」「草稿」接口权限——真正发的时候还可能因为权限不足报错。

如果你有多个公众号，可以在这里保存多套凭证，发布时在编辑台里切换。只用一个号的话不用管这里。

热点接口进阶

热点捕捉默认走开源 DailyHotApi （公共地址 https://api-hot.imsyy.top/）。如果公共服务被限流，建议自己用一行 Docker 跑一份，再把地址填到这里：

docker run -d --name daily-hot-api -p 6688:6688 imsyy/dailyhot-api:latest

抓取顺序：先 DailyHotApi，失败时自动回退到 NewsNow，再失败才提示错误。

DrissionPage 增强抓取可选 / 进阶

遇到反爬严重、需要登录的页面时，可以在本机起一个 DrissionPage helper 服务（自带 Chromium），扩展会优先把抓取请求转给它；helper 不可达或抓不到内容时会自动回退到内置抓取，不会让你卡死。

选区抓取（在网页上选中文字 → 抓取）永远走扩展内置脚本，不经过 DrissionPage。

测试只检查 helper 的 /health 接口可达。真正抓取效果取决于目标站点 + 浏览器内核。

AI 选题代笔 Agent进阶

为 AI 选题代笔 控制台设默认值：默认勾选哪些平台、每平台抓多少条、并发与抖动、是否调用一次 AI 生成选题总结。这些值仍可在控制台临时修改。

凭据完全靠浏览器自身 cookie，扩展不存账号密码。如未登录，对应平台会被自动跳过。
