    自定义 API Key：用你自己注册的 OpenAI / DeepSeek / Kimi 等服务商账号，文章正文直接发送到你绑定的服务商，不经过润笔服务器。仅年费会员可解锁。

    加载用量中...

    高级生成参数 去 AI 味推荐档位 · 留空 = 服务端默认

    这三个参数都是 OpenAI 兼容 API 的标准字段。留空时不会下发给服务端，由模型按默认值处理；填上时会随每次改写一起发出去。 推荐"去 AI 味档位"：top_p 0.92、frequency_penalty 0.5、presence_penalty 0.3，配合 temperature 0.85 使用，能在大多数 OpenAI / DeepSeek / Qwen 兼容服务上把句长方差和用词丰富度推高。

    默认改写偏好可选

    这些偏好会在每次打开编辑台时自动填入，你仍然可以在编辑时临时调整。留空也能用，AI 会按内置默认风格写。

    开启后 AI 改写和抓取**不再阻塞编辑台**——任务挪到右下角浮窗后台跑，等待期间你可以切到别的草稿、抓下一个网页或看 dashboard。任务完成会弹 toast 提醒并能跳到对应文章。 什么时候关：习惯看到"全屏 loading 等结果"才安心；或并发跑多个改写时担心服务商速率限额。 关掉的后果：回到老的全屏 loading modal 模式，等待期间不能做其他操作。可以随时打开。

    去 AI 味强化PRO · 默认开

    开启后，AI 改写完成的文章会再过一道"去 AI 味"专项润色，句长、用词、节奏会被重写到更接近真人写作。这一步会触发额外的 LLM 调用（按章节数计 N 次），改写时间和 token 用量会有 30%–80% 的增加。

    token 估算：一篇 1500 字稿件，主 pass 大约 ~2.5k token；中档位通常只重写 1–3 段（~1.5k–3k token），重档位按章节数（典型 4–6 章）总计 ~3k–5k token。lint 分数 ≥ 85 时整篇会跳过二次润色，直接用主 pass 结果。

    我的文风可选 · 让 AI 模仿你的语气

    把你以前写过的几篇代表作粘进来，AI 会先离线提取一份"风格指纹"（常用语气词、句长偏好、忌讳词）， 之后所有 AI 改写 + 二次"去 AI 味"润色都会向这份指纹靠拢。 样本只存在你本机浏览器，不会上传到我们的服务器；但每次改写时会随 prompt 发给你配置的 LLM API 提供方。

    最多保存 8 份，每份原文最长 12000 字。同一时间只能启用 1 份。

          微信 API 代理地址（动态 IP 用户必备 / 高级）
          
          
          
            如果你家用宽带 / 4G/5G 是动态 IP 进不了公众号后台白名单，会反复报 40164。
            把请求中转到一台有固定出口 IP 的代理就能解决。推荐用阿里云函数计算（FC）：
            个人版有免费额度，FC 出口 IP 是阿里云固定段，把这段 IP 一次性加白名单后所有 cgi-bin 接口就都通了。
            一键部署模板见仓库 aliyun-fc/wechat-api-proxy/。
          
          
          
          
            ⚠️ Cloudflare Workers 不适合做这件事：CF 出口是动态 IP 段，每天换，加白名单白加了。
