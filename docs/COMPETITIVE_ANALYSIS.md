## 二、润笔优势（差异化护城河）

1. **「抓取任意网页 → AI 改写成自己的稿」二创链路**：竞品 AI 是「输关键词从零成文」或「素材图片采集」；润笔强在抓正文喂 AI 改写。洗稿/二创/编译型创作者刚需，竞品弱。
2. **「去 AI 味」三层防线**（humanize-rules / lint / 二次润色）：2026 年 AI 检测/原创度判定趋严，竞品 AI 产出一眼 AI 味。**最锋利的认知差异化单点，应作对外主打。**
3. **杂志级母版**（New Yorker / Wired / Monocle / Vogue / Kinfolk / Paper）：竞品「海量但同质化、套模板感重」，润笔走「少而精、去模板感」。
4. **BYOK + 平台 AI 双模式 + 本地优先隐私**：年费用自己的 key、正文不过润笔服务器；数据存本机。竞品全是平台托管（正文上传）。
5. **个人文风指纹**：让 AI 模仿「你自己」语气，竞品无。
6. **价格更低**：¥29月 / ¥288年，显著低于壹伴 ¥99月 / 135 企业版。

## 四、战略判断

**不要正面拼「全家桶 + 海量模板 + 素材库 + 数据大盘」**——竞品多年护城河，补不平也偏离定位。

**润笔甜区**：靠「读资料 → 二次创作 → 高质量原创」吃饭、重内容质量/原创度/隐私、不在乎海量模板和运营数据的**知识型/观点型作者**（科技、商业、出海、深度评论赛道）。

### 补强优先级（按 ROI）
1. **敏感词/违规检测**（劣势 #5）——公众号合规硬门槛，缺它专业作者不敢用；本地词库实现成本低，**最该先补**。
2. **基础配图能力**（劣势 #2）——哪怕接一个无版权图搜索 + 封面尺寸裁剪，补「找图」高频断点。
3. **对外主打「去 AI 味」单点**——比「又一个排版工具」好讲故事。

### 不建议追
SVG 动效、10万模板库、团队协作、数据大盘——投入大、竞品主场、偏离定位。

## 五、Chrome Web Store 上架就绪度（40th session 评估）

**工程层面无硬阻塞**，剩余是操作性步骤（≈ 半天）+ 审核（1-7 天）。

### 已就绪（~80%）
- manifest MV3 合规、权限最小化（动态 URL 走 optional 按需申请）、CSP 无远程脚本、单一用途清晰
- 商店文案全套 + 逐权限 justification（[STORE_LISTING.md](./STORE_LISTING.md)）
- privacy/terms 页面已存在（Cloudflare Pages 自动部署）
- 5 张截图 + 推广图设计稿（`assets/store/*.html`）
- 打包链路 `npm run release:cws` + `scripts/cws-capture.mjs`

### 还差（操作性）
1. `npm run release:cws` 重新打包扩展 zip（40th 改了 license/ai/sw 等，必须重打）
2. `node scripts/cws-capture.mjs` 生成 `dist/store/` PNG（需 `npx playwright install chromium`）
3. 浏览器确认 `docuearn.com/privacy` `docuearn.com/terms` 公网可访问
4. 干净 Chrome profile 实测主流程（验证 40th 改动无回归，尤其会员卡/BYOK 闸门）
5. $5 开发者注册费
6. 提交审核（建议首发 trusted testers 灰度）

### 审核风险点
- `optional_host_permissions: https://*/*` + 较长 host 列表较敏感——justification 已写明「仅用户主动触发时申请单一 origin」，被问按文案回复。
- 平台 AI 数据流披露已诚实写明（加分项）。
