# 浏览器登录模式（Browser Login Mode）

> 让 C 端创作者不必申请 AppID/AppSecret、不必把动态 IP 加白名单，也能把改写好的稿件送进公众号草稿箱。

## 一句话原理

扩展打开你已经登录的「公众号后台编辑页」，把**标题/摘要/作者/原文链接/正文 HTML** 直接写进编辑器表单。最后一步「保存为草稿」由你在 mp 后台手动点（合规底线，不自动点）。

不调任何官方 API，不读取 access_token，不绕过登录态。

## 与 API 模式的区别

| 维度 | 浏览器登录模式（推荐 C 端） | API 模式（适合服务器/固定 IP） |
|---|---|---|
| 需不需要 AppID + AppSecret | 否 | 是 |
| 需不需要 IP 白名单 | 否 | 是（家用动态 IP 大概率不通） |
| 同步内容 | 标题、摘要、作者、原文链接、正文 HTML | 全部 + 封面图自动上传 |
| 封面图 | ⚠️ 手动在 mp 后台上传 | ✅ 自动 |
| 「保存为草稿」按钮 | ⚠️ 手动点 | ✅ 自动 |
| 群发 / 定时发布 | ❌ 不支持 | ✅ 支持 |
| 多图文 | 仅同步第一篇，其余手动 | 一次性整包发送 |

## 最佳使用场景

**用浏览器登录模式**：
- 个人/工作室创作者，没有 AppID
- 家用宽带或 4G/5G 出口 IP 经常变动
- 已经被 errcode 40164（IP 不在白名单）卡过
- 单图文、不需要群发的日常推送

**用 API 模式**：
- 已经把出口 IP 加进白名单的成熟用户
- 需要群发到全员/标签
- 需要程序化批量发布
- 多图文一次性整包推送

## 操作步骤

### 1. 在设置页新建账号

1. 打开扩展设置页 → 「多账号管理」
2. **发布通道** 选「浏览器登录模式（推荐）」
3. 填一个账号名称（例如「主号」）→ 点「添加公众号」
4. AppID / AppSecret 字段会自动灰显，可以不填

### 2. 在公众号后台保持登录

1. 浏览器开一个 tab 打开 <https://mp.weixin.qq.com/>
2. 用账号密码或扫码登录（任选其一）
3. 不需要停在编辑页——扩展会自动跳转

### 3. 改写完成后点发布

1. 在编辑台改写完成后，点「推送到公众号草稿箱」
2. 扩展会自动打开（或聚焦到）公众号编辑页
3. 编辑页右下角会出现绿色助手 dock，显示标题/摘要/正文写入状态
4. 按 dock 上的清单完成最后 3 步：
   - ① 检查标题/正文是否完整
   - ② 在 mp 后台「封面」处上传封面图
   - ③ 点右上角「保存为草稿」按钮

## 切换模式

- 已有账号可以双向切换：在多账号卡片上点「切到 API」/「切到浏览器登录」
- 切换不会清空 AppID/AppSecret，方便日后再切回去

## 常见问题

**Q：扩展会读我的 cookie 吗？**
A：不会。扩展只通过 chrome.tabs.sendMessage 把 HTML 内容发给一个内容脚本（content script），由这个脚本在 mp 编辑页的 DOM 上模拟你手动输入。整个过程在你已登录的浏览器 tab 内进行，扩展拿不到 cookie，也不发任何带 cookie 的请求到第三方。

**Q：会不会违反公众号用户协议？**
A：扩展只是「智能填表」助手，不调任何 mp 内部 API、不自动点保存按钮、不操作账号外的任何资源。最后一步保存草稿由你手动点击。这与浏览器自带的「自动填充」性质相同。

**Q：mp 后台改版了，写不进去怎么办？**
A：dock 上有「复制正文 HTML」按钮，点完到 mp 后台正文区右上角点「&lt;&gt; HTML 源码」粘贴即可。

**Q：登录态丢了会怎样？**
A：扩展能识别（编辑页跳转到登录页）并提前抛错，同时帮你自动打开 <https://mp.weixin.qq.com/>，登录后回扩展点重试即可。

**Q：可以同时管理多个公众号吗？**
A：可以——每个账号是独立 profile，发布前在编辑台「发布账号」下拉里选。但浏览器只能保持一个 mp 后台登录态，多账号需要在切换前先登出再登入目标账号。
